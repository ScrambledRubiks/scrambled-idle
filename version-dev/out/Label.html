(static) O(obj, id, container, innerHTML, css, tooltipHTML, shown, icon, resFormat, resSuffix)

Creates a DisplayElement based on an object with the parameters of DisplayElement. Note: JSDocs shows the function as having all of the parameters, but the function only has the one object parameter. The rest are parameters for the object, see the example for correct usage.
Parameters:
Name Type Description
obj object The object to be constructed into a Res. The following are parameters for the object and not for the function itself:
id string The Label's id.
container string The id of the container to add the label to.
innerHTML string The label's HTML.
css string (optional) The label's CSS class, default is none.
tooltipHTML string (optional) The label's tooltip HTML, default is none.
shown boolean (optional) Whether or not the label should be shown on game load, default is true.
icon string (optional) An icon URL for the DisplayElement, default is none.
resFormat Res (optional) A resource to display in the Label, default is none.
resSuffix string (optional) A string to add after the resource's amount, default is none.
