UpgradeGroup(id, container, containerCSS, upgradeCSS, defaultPurchaseBehavior)

new UpgradeGroup(id, container, containerCSS, upgradeCSS, defaultPurchaseBehavior)

Creates a new UpgradeGroup.
Parameters:
Name Type Description
id string The UpgradeGroup's id.
container string The UpgradeGroup's container.
containerCSS string The UpgradeGroup's CSS class, default is none.
upgradeCSS string The UpgradeGroup's upgrade CSS class, default is none. Applied to all upgrades in the UpgradeGroup, but not the UpgradeGroup itself.
defaultPurchaseBehavior function A function that is called when an upgrade in the group is purchased. Note that defaultPurchaseBehavior is run in the Upgrade environment so the 'this' is the upgrade object, which has all methods from Button.
