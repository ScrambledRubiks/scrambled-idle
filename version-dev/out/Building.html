Class: Building

Building(name, id, container, flavor, req, effect, defaultPurchaseBehavior, cost, amount, buildingCostIncrease, buildingCSS, currency)

new Building(name, id, container, flavor, req, effect, defaultPurchaseBehavior, cost, amount, buildingCostIncrease, buildingCSS, currency)

Creates a building. You probably shouldn't call this directly, instead to create a building call the b() method on a BuildingGroup.
Parameters:
Name Type Description
name string The building's name.
id string The building's id.
container string The container to add the building to.
flavor string The building's flavor text.
req function The requirement for the building to be visible.
effect function The building's effect when purchased.
defaultPurchaseBehavior function A set of default behaviors when the building is purchased, defined in each buildingGroup.
cost * The cost of the building.
amount number The amount of the building.(also known as a)
buildingCostIncrease number Some number that the cost of the building is multiplied by every time the building is purchased.
buildingCSS string The building's CSS class, default is none.
currency Res The currency to use for the building's cost.
